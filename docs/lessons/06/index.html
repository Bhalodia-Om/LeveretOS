06 · Scrolling

Shift lines up when text reaches the bottom.

What this lesson adds

Until now, printing past the bottom row (row 25) wrote beyond the screen. Now when the cursor goes past the last row, every line is shifted up, and we free the last line. The demo prints 40 numbered lines so the earliest ones scroll off the top.

Boot it in your browser

Run the LeveretOS lesson-6 ISO, emulated with v86.

The OS is ran in your browser, nothing installed. The emulator + ISO may take a few moments to load.
