14 · Physical Memory

Track which chunks of RAM are free or used, with a mem command in the shell.

What this lesson adds

This lesson we added a physical memory manager. We read the memory map GRUB gives us to learn how much RAM the machine has and which parts are usable. We then track every 4 KB chunk of RAM as free or used. We can then hand out free chunks of RAM, and take it back after. This also protects the kernel's memory so it is never used by other systems. A mem command prints out how much RAM is usable, used, and free. We will need this for paging and a memory allocator in the next few lessons.
