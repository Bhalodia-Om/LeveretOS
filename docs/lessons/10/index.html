10 · Interrupts (IDT)

Our own interrupt table, so that the CPU uses our code when something happens, rather than a failure.

What this lesson adds

This lesson adds the IDT (Interrupt Descriptor Table). The IDT tells what code to run when an interrupt happens. We set up handlers for CPU exceptions in this lesson, like dividing by 0. To show it works we divide by 0 on purpose. Our handler now catches the errors and halts the OS, rather than a reboot loop. Sets us up for lesson 11.

Heads up: Nothing to play on this lesson. We divide by zero on purpose, testing our handler to catch the error and halt. Rather than rebooting, we stop.
