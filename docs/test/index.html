What this is

The lessons show you the code. This guide explains the ideas underneath it. If a lesson writes 0x9A into a permission byte, the lesson tells you it works, and this guide shows you exactly which bits that number turns on and lets you click them yourself.

The target reader finished a first programming course. You know what a variable, a loop and a function are. You have probably never used a bit mask in anger, never thought about which end of a number comes first in memory, and never written to a hardware port. Everything past that point gets explained here.

How to use it

Read in order if you are starting out, the Foundations pages come first for a reason. Later pages assume you know hex, masks and byte order. If you came here from a specific lesson, jump straight to that page and follow the links back when something is unfamiliar.

Nearly every page has things to click. Flip bits and watch a hex value change, step through a boot sequence one line at a time, move a ring buffer's pointers around. That is deliberate: these ideas stick when you drive them yourself, and they slide right off the page when you just read about them.
