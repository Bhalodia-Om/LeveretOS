LeveretOS
An operating system built from scratch, one lesson at a time.

Welcome. LeveretOS is a small operating system written completely from scratch in C++. There is no Linux, no Windows, nothing underneath it, just our own code running directly on the machine, starting from the very first instruction at boot. It is built as a series of lessons: each one adds a single new feature on top of the last, and every new piece of code is commented for beginners. The whole project can be read like a step-by-step guide to how an operating system actually works, from a blank screen all the way toward connecting to the web.

Note: you are viewing the classic-web version of this site. It is plain HTML with no JavaScript, made to be light and fast and readable on almost anything, including the little browser that LeveretOS is being built to have one day. The modern version, with a live in-browser emulator for every lesson, is linked at the bottom of the page.

Why "LeveretOS"?

A leveret is a baby hare, small, quick, and one of the fastest-growing young animals around. It felt like the right mascot for an operating system that started as almost nothing and grows a little better with every lesson.

The project started with nothing but a boot message on a black screen. Lesson by lesson it has learned to move a cursor, read the keyboard, print numbers, scroll like a real terminal, play a game, and, most recently, take control of the processor's memory segments and interrupts. Like the animal it is named after, it is small and quick, and it is growing fast.


The idea

Each lesson has its own numbered folder and adds one new feature on top of the last. New or changed code carries comments to walk you through each step, while code reused from earlier lessons is left uncommented so the new work stands out. Every lesson can be built into a bootable image and run in an emulator, or booted right in your browser on the modern site.

The goal

The first big goal is a version of LeveretOS that can go online and open a web page. These are the checkpoints along the way, ticked off as we reach them:

[x]Play a game (Rock Paper Scissors)   — done
[ ]Type commands into it, like a real terminal
[ ]Show a running clock
[ ]Greet you with a login screen at startup
[ ]Draw real graphics on screen, so the browser has a display
[ ]Open a page from the web

Once it can browse the web, the goals get bigger. This is where LeveretOS grows from a single program into something closer to a real operating system:

[ ]Log in securely, with a real password
[ ]Create, open, and manage files
[ ]Write and save notes in a text editor
[ ]Run separate apps, instead of everything being one program
[ ]Open the web browser as one of those apps

09. GDTOur own segment table, so the kernel controls its own code and data.

Building it yourself

Each lesson folder is self-contained. It includes a build script that assembles the bootloader, compiles the kernel, makes a bootable ISO, and launches it in QEMU. You will need nasm, a 32-bit-capable g++, grub-mkrescue, xorriso, and qemu-system-i386. On Windows, a Linux environment such as WSL works well. If you would rather not install anything, there is also a Docker image that provides the whole build environment. A good starting guide for the toolchain is OSDev Bare Bones.
